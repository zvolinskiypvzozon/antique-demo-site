# Демо-сайт: скупка антиквариата

Статичный адаптивный сайт (HTML, CSS, JavaScript) для демонстрации верстки. Все тексты, контакты, имена и отзывы условные.

## Что показывает демо
- Шапка на всю ширину, контент по центру в контейнере 1160 px
- Мягкие скругления и подсветка карточек при наведении
- Мобильное меню без библиотек, адаптив 390 / 768 / 1440 px
- Контакты (телефон, адрес, график) меняются в одном файле `config.js`, ссылки `tel:` формируются автоматически
- Форма заявки (в демо данные никуда не отправляются)

## Запуск
Откройте `index.html` в браузере или выполните `python3 -m http.server 8000` и перейдите на http://localhost:8000

## Что не входит в демо
WordPress, Elementor, Contact Form 7 и уведомления в Telegram. Это статичная вёрстка, а не CMS.
